# 🐱 Sokak Kedisi Sohbet Simülatörü

## Projenin Amacı ve Tarihsel Önemi

Bu proje, insanlık tarihinin en önemli sorularından birini yanıtlamak üzere tasarlanmıştır: **Sokak kedileri gerçekten ne konuşuyor?**

Yıllarca süren (yaklaşık 3 dakika) yoğun araştırmalar sonucunda, kedilerin aslında çok derin felsefi ve sosyolojik tartışmalar yaptığı ortaya çıkmıştır. Bu simülatör, o tartışmaları %99.7 doğruluk oranıyla (kaynak: ben) yeniden canlandırır.

## Kurulum ve Kullanım

1. Python 3 yüklü olsun (yoksa üzülürüz).
2. Terminali açın ve şunu yazın:
   ```bash
   python main.py
   ```
3. Kedilerin bilgeliğine tanık olun.
4. Şaşırın. Sonra tekrar şaşırın.

## Özellikler

- Gerçek zamanlı kedi düşünme süresi simülasyonu (0.8 saniye)
- Rastgele sohbet seçimi (matematiksel olarak adil)
- Hiçbir kedi zarar görmemiştir (sanal oldukları için)
- Kapitalizm, demokrasi ve kuyruk sallama gibi derin konular işlenmiştir

## Uyarılar

Bu programı çalıştırdıktan sonra kedilere farklı bakabilirsiniz. Sorumluluk kabul etmiyoruz. Eğer bir kedi size "miyav" derse, bu simülatörün suçu değildir.

## Katkıda Bulunma

Pull request gönderin. Kediler onaylarsa merge ederiz. (Kediler her zaman onaylar.)

## Lisans

Bu proje MIT lisansı altındadır. Yani istediğinizi yapabilirsiniz, ama kedilere saygı duyun.
